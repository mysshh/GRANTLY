How it works.

THE PROBLEM WE ADDRESS

Scholarship information is scattered. The next step shouldn't be.

Students often need to search multiple portals, interpret different eligibility rules, keep track of deadlines and prepare documents across disconnected places. GRANTLY brings those planning steps into one student-focused workspace.

01 · Discover

Browse the in-app scholarship catalogue. Search by name, provider, course or audience and narrow results by category and deadline.

Open the directory ↗

02 · Match

SmartMatch compares the profile fields students provide with known catalogue tags. It separates potential matches, listings needing more information and clear mismatches, with a reason for each classification.

Try SmartMatch ↗

03 · Organise

Save opportunities, record application stages and deadlines, compare saved entries and maintain a preparation checklist.

Open application tracker ↗

04 · Prepare

Use the Eligibility Decoder, Deadline Radar, Document Vault checklist, Funding Copilot templates and Readiness Score to plan the next action.

Explore student tools ↗

  • National Scholarship Portal — All Scholarships

Each catalogue entry links to an official or scheme-authority source. Some entries point to a central directory rather than a scheme-specific application form.

TECHNICAL DESIGN

Small, separated modules

  • Semantic HTML pages with a shared responsive stylesheet.
  • Browser modules for navigation, catalogue, SmartMatch, tracker, student tools and account navigation.
  • Hatchable-hosted API and PostgreSQL profile record for signed-in passport sync.
  • Browser local storage for preferences, tracker entries and checklist metadata.

Account profile access is scoped to the authenticated user by the API and database ownership policy.

PRIVACY & SAFETY

Keep sensitive information out

GRANTLY does not ask for Aadhaar numbers, bank account numbers, passwords or copies of identity documents. The Document Vault is a checklist only. Local-first tools remain in the current browser; the Scholarship Passport can be synced to the signed-in account.

Important: GRANTLY is an independent discovery and planning tool, not a government portal, scholarship provider or legal/financial adviser. Scheme availability, eligibility, award amounts and deadlines can change. Always verify the latest official notification and confirm requirements with your institution or scheme authority.

QUALITY CHECKLIST

Before each release

  • Check each page at desktop and mobile widths; verify navigation and keyboard focus.
  • Confirm all JavaScript modules load and the catalogue is available on both the directory and SmartMatch pages.
  • Test SmartMatch form submission, result categories, save-to-tracker actions and edit-profile flow.
  • Test tracker create/edit/delete/filter, deadline calculations, compare and readiness updates.
  • Test passport account load/save and verify that one account cannot read another account's profile.
  • Run Hatchable's deployment dry-run and manually test the anonymous and signed-in views.
